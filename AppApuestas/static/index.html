PitchAPI · fuente principal

Elige una liga y su temporada disponible. El análisis muestra únicamente futbolistas vinculados al partido seleccionado; las alineaciones se identifican como confirmadas o provisionales.

La cobertura depende del partido. Una alineación previa al inicio puede ser una predicción; el sistema no la presentará como confirmada. xG y estadísticas se muestran solo cuando la fuente las proporciona.

Contraste de alineaciones y estadísticas

TheSportsDB · API pública

Busca la cartelera de una fecha y consulta alineaciones, eventos y estadísticas adicionales cuando TheSportsDB tenga cobertura. No reemplaza los datos principales de PitchAPI.

API gratuita · clave pública compartida · límite publicado de 30 solicitudes por minuto.

El acceso gratuito tiene límites por endpoint y la cobertura varía. Las fichas de jugadores se muestran como muestra parcial de hasta 10 registros activos por club. Confirma alineaciones y estadísticas con PitchAPI antes de utilizarlas en predicciones.

NBA Research · Tiros, rosters e historialesNBA.com Stats · mapas de lanzamiento · game logs
Fuente separada de fútbol

Este módulo utiliza estadísticas y coordenadas nativas de NBA.com. Los mapas representan tiros de baloncesto, no se mezclan con xG ni con coordenadas de fútbol. La disponibilidad depende del acceso que NBA.com permita desde Render.

NBA.com Stats · elige una fecha y consulta la cartelera para comenzar.

Las estadísticas de partidos, tiros y rosters dependen de los datos publicados por NBA.com y pueden sufrir límites de acceso. Las listas de jugadores se consultan por temporada para reducir el riesgo de mostrar plantillas antiguas.

Cómo interpretar estos datos

Las probabilidades son estimaciones del modelo a partir de los históricos disponibles. El EV se calcula únicamente cuando hay una cuota publicada y una predicción compatible. Una estimación no garantiza un resultado ni constituye una recomendación de apuesta. El EV es exploratorio: el modelo aún no está validado fuera de muestra ni calibrado; no representa una ventaja comprobada.
